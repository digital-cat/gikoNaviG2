# ギコナビ(避難所版II) ﾊﾞﾀ75(1.76.0.917) 検証版#02 2025/05/25

本ソフトウェアは、ギコナビ避難所版 ﾊﾞﾀ70(1.71.0.861)からの改造版です。

このバージョンは、OpenSSL3への対応を検証するためのものです。
使用しているIndy通信ライブラリが開発途中の未完成版であるため、
正常に動作しない可能性があります。
使用中のギコナビとは別のフォルダにインストールしてください。

### ﾊﾞﾀ75(1.76.0.917) 変更内容
- OpenSSL 3.5.0 に更新
- 投稿時刻エラー処理追加
- 現役ではないスレのアイコン追加・書き込み抑制
- まちBBSプラグイン処理URL最新化
- Win11表示不具合対策初期値変更（Win11以降初期値有効）

### ﾊﾞﾀ75の主な変更点
- どんぐり対応
- 板別Cookie管理廃止
- IPv6対応
- NGワード形式に正規表現２（SkRegExp）追加
- その他改良／不具合修正

### 開発環境
- Delphi 2007
- Indy10
- OpenSSL
- Tnt Delphi UNICODE Controls
- bmRegExp
- SkRegExp
